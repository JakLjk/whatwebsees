What this result means

The count describes this document only. A valid sitemap helps discovery, but it does not prove that search engines fetched, accepted or indexed its URLs. A sitemap index can point to additional sitemap files.

How to use a sitemap result

A URL set lists pages directly, while a sitemap index lists other sitemap files. Last-modified values are optional publisher hints and may be absent or outdated.

Technical limits

The checker reads one size-limited XML document, rejects external entity declarations and recognizes standard urlset and sitemapindex roots. It does not recursively crawl nested sitemaps or submit anything to a search engine.
