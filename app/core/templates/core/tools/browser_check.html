How websites detect browsers

Websites can inspect the User-Agent, newer Client Hints and feature support exposed by browser APIs. This checker uses a small set of conservative rules and labels uncertain device-class results as indications rather than facts.

Why browser detection can be inaccurate

User-Agent strings contain compatibility tokens, browsers can share the same rendering engine, and privacy tools may standardize or spoof details. Feature detection is usually better for deciding whether a web feature works; browser names are mainly useful as a human-friendly summary.
