How the main metadata fields are used

The title and description summarize a page, while a canonical link identifies its preferred address. A robots directive can request indexing behavior. Open Graph and Twitter fields provide suggested titles and descriptions when a link is shared.

Why another service may show something different

Search engines and social platforms can rewrite text, use cached metadata or ignore fields that do not match the page. This checker reads the first matching values from the initial HTML and does not run scripts, load images or judge the page's visual content.
