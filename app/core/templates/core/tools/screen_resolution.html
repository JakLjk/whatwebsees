What does my screen resolution result mean?

Reported screen size

The main answer is screen.width × screen.height, the full active screen size reported by the browser in CSS pixels. It is not necessarily the panel's advertised hardware-pixel resolution. Browser privacy protections, operating-system display scaling, zoom and the active monitor can affect what is reported.

Screen resolution vs viewport size

The screen describes the broader display. The browser viewport is only the page's current layout area inside browser controls, so screen resolution is not the same as browser viewport size. The viewport changes when you resize the window, open side panels or developer tools, change zoom, show an on-screen keyboard or rotate a mobile device.

Available screen area

screen.availWidth and screen.availHeight estimate the screen space available to windows. They can exclude operating-system interface areas such as a taskbar or dock, which is why the available area may be smaller than the reported screen size.

CSS pixels and device pixel ratio

A CSS pixel is the layout unit used by web pages; it does not always map one-to-one to a physical display pixel. Device pixel ratio (DPR) describes the browser's current ratio between CSS pixels and device pixels. A DPR of 2 commonly means the browser uses a two-by-two block of device pixels for one CSS pixel in each dimension.

Estimated physical-pixel dimensions

The estimated device-pixel dimensions multiply the reported CSS screen size by DPR. This is useful context for Retina and other HiDPI displays, which use extra device pixels to render sharper content, but it is still an estimate. Display scaling, browser zoom, privacy reduction, spanning and multi-monitor behavior can prevent it from matching a monitor's specification exactly.

Browser zoom and orientation

Page zoom can change the size of a CSS pixel and the reported DPR, while pinch zoom may affect the visible area differently from layout zoom. Orientation reports the browser's view of the current screen orientation and angle; rotating a device can swap width and height and trigger a live update above.

For related context, compare the browser and platform summary, inspect the reported User-Agent, review graphics exposure with the WebGL Checker, or see other browser-visible signals in the Privacy Check.
