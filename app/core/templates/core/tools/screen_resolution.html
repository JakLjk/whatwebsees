Understanding screen resolution testing

What is screen resolution?

Here, screen resolution means the width and height reported by the browser's screen API in CSS pixels. Browser privacy settings, operating-system display scaling and the active monitor can affect the reported result.

Screen resolution vs viewport size

The screen describes the broader display area. Available screen size normally excludes operating-system interface areas such as a taskbar. The viewport is the space currently available to this page inside browser controls and changes when you resize the window, open browser panels or rotate a device.

What device pixel ratio means

A CSS pixel is the layout unit used by web pages; it does not always map one-to-one to a physical display pixel. Device pixel ratio describes the browser's current ratio between CSS pixels and device pixels. The estimated device-pixel dimensions multiply the two browser-reported values, but zoom, scaling, privacy reduction and multi-monitor behavior mean this should not be treated as guaranteed panel hardware resolution.
