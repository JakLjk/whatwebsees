302 FoundA temporary destination.Browsers commonly change POST to GET when following it.
303 See OtherRetrieve a separate result, often after a form submission.The follow-up uses GET (or HEAD), which supports the POST/Redirect/GET pattern.

When redirect chains become a problem

One intentional redirect, such as HTTP to HTTPS, is common. Long chains add delay and make maintenance harder, while a loop prevents the destination from loading. The checker stops at a fixed limit and reports each completed hop.

Technical safety

Every destination is checked again before the server follows it. Credentials, non-standard ports and hostnames that resolve to non-public addresses are refused.

Read the fuller guide to HTTP redirects and status codes, or inspect the destination's selected response fields with the Server Headers Checker.
