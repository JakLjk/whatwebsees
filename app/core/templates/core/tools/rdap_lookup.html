Why RDAP instead of legacy WHOIS

RDAP returns structured JSON over HTTPS and supports standardized registry discovery. The checker first retrieves IANA’s bootstrap registry and then contacts the listed HTTPS service through the same public-address-only network layer. Personal registrant fields are intentionally not displayed.
