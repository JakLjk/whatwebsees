All calculations happen in this browser. KB, MB, GB and TB use decimal multiples; Kbps, Mbps and Gbps are bits per second.

How the estimate works

The calculator converts file bytes to bits, divides by the selected bits-per-second rate and formats the duration. For example, one decimal gigabyte contains eight gigabits before overhead.

Why real downloads take longer

The ideal estimate does not include protocol overhead, latency, congestion, Wi-Fi interference, retransmissions, server limits or competing traffic. Advertised access speed may also differ from throughput to a particular server.

Calculator, not measurement

No file is downloaded and no network performance is tested. Use the estimate for planning, then allow a margin for real-world conditions.
