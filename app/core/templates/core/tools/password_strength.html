What this heuristic can and cannot tell you

The label considers length, variety and a few obvious repetition patterns. It cannot know whether the same password is reused elsewhere, whether it appears in a breach, or exactly how quickly a particular attacker could guess it.

Length and uniqueness matter most

A long unique passphrase is generally more useful than a short password made complicated only to satisfy composition rules. Avoid predictable personal phrases and do not reuse credentials between services.

Password managers

A reputable password manager can generate and store a different random password for each account. Enable multi-factor authentication where available, especially for important accounts.
