Useful diagnostics with a smaller privacy footprint

These tools use standard browser features to make otherwise hidden technical details easier to understand. Screen, browser, canvas and WebGL results stay in your browser. The headers checker requests only the existing safe server allowlist; sensitive headers such as cookies and authorization credentials are excluded.

Browser-reported values can be reduced, standardized or changed by privacy settings and extensions. Treat the results as a view of this browsing context, not proof of an exact device or a person's identity.
