Useful diagnostics with clear privacy boundaries

Browser and calculator tools run locally whenever possible. Network tools validate inputs, reject non-public destinations, use short timeouts and return only the details needed for the result. WhatWebSees does not create a history of submitted diagnostic values.

Results are snapshots. DNS, certificates, HTTP responses and browser capabilities can change, and location from an IP database is approximate rather than a precise physical position.
