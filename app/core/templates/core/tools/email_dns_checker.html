What this result means

MX tells senders where mail should go; SPF names permitted sending infrastructure; DKIM publishes a key used to verify signed messages; and DMARC states how aligned SPF/DKIM results should be handled. Published records do not prove that every message authenticates, that a mailbox exists, or that mail will be delivered.

A conservative DNS inspection

This checker displays relevant DNS records and extracts only the top-level DMARC policy. It is not a complete RFC policy evaluator. DNS caching, split-horizon DNS, selector choice and staged policy changes can all affect what is observed.

Use DNS Lookup to inspect other public record types and DNSSEC Checker to review DNSKEY and parent DS evidence.
