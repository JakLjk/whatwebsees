Hostname lookup versus DNS lookup

This tool answers the common question “which public IP addresses does this hostname resolve to?” It combines and deduplicates address results rather than exposing every DNS record type.

For mail routing, name servers, verification text, aliases and zone authority, use the more detailed DNS Lookup. DNS answers can vary over time due to TTL-based caching and traffic distribution.

Why non-public answers are rejected

WhatWebSees does not disclose or connect to internal destinations. If any resolved candidate is private, loopback, link-local, reserved or otherwise non-global, the whole lookup fails closed.
