Crawling controls are not access controls

robots.txt asks compliant crawlers which URLs they may fetch. The file is public and does not protect private content. Blocking a URL also does not reliably remove it from search results; a noindex instruction is a separate indexing control.

How this checker works

The checker requests only the site's /robots.txt file, limits the response size and lists basic User-agent and Sitemap directives. It does not crawl the listed pages.
